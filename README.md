# 📈 Sales Forecasting System

A Machine Learning project that predicts future sales using historical sales data.

This project was developed as part of the Data Science Internship - Phase 2.

## 🚀 Project Overview

The system analyzes historical sales data, discovers trends, and predicts future monthly sales using Machine Learning techniques.

The project includes data preprocessing, exploratory data analysis, model training, evaluation, and an interactive Streamlit dashboard.

## 🎯 Objectives

- Analyze historical sales trends
- Perform data preprocessing
- Build a machine learning prediction model
- Evaluate model performance
- Create an interactive dashboard for predictions

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Joblib

## 📊 Features

✅ Data Cleaning & Preprocessing  
✅ Exploratory Data Analysis (EDA)  
✅ Monthly Sales Trend Visualization  
✅ Sales Prediction Model  
✅ Model Performance Evaluation  
✅ Interactive Streamlit Dashboard  

## 🤖 Machine Learning Model

Model Used:

- Linear Regression

Evaluation Metrics:

- MAE: 11,599.75
- RMSE: 17,017.19
- R² Score: 0.49
